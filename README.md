# Curiosity Shorts Studio

نظام مستقل لإنتاج فيديوهات Pip وRay: موضوع ومصادر، حوار، صوتان، رسوم متحركة، ترجمة، فحص جودة، ثم رفع اختياري إلى YouTube.

**عدد الفيديوهات الافتراضي 1**، ويتغير من `video_count` عند التشغيل أو من `studio.json`.

## التشغيل من GitHub Actions

1. افتح **Actions → Generate science videos → Run workflow**.
2. اختر `starter` لتجربة المشاهد المرسومة يدويًا، أو `new-topic` لإنشاء موضوع وحوار وSEO ومخطط سببي جديد بنموذج محلي مجاني.
3. اترك `video_count=1` للاختبار الأول. اختر الصوت `kokoro` للعمل بدون خدمة صوت خارجية، أو `edge` لمحاولة الأصوات الأصلية.
4. بعد النجاح، نزّل `video-bundles` من صفحة التشغيل. يتضمن `final.mp4` كاملًا، `captions.srt`، `review.jpg`، `qa.json`، `episode.json`، `manifest.json` وملفات البحث عند توليد موضوع جديد.
5. هذه الخطوة **لا تنشر أي فيديو** على YouTube. التحميل إلى القناة عملية منفصلة موضحة أدناه.

الأثر المحفوظ في Actions ينتهي بعد يوم لتقليل التخزين، فنزّله قبل انتهائه.

## ما الذي يطابق الأسلوب الأصلي؟

- مكتبة الشخصيات نفسها، رأسان دائريان بدون أجسام، تعابير، نظارات، حركة فم، خلفيات ومخططات علمية.
- قوالب متخصصة: صوت البطن، الفواق، الدوار، البصل، وصداع المثلجات. بعض القوالب القديمة تحتاج إعادة مراجعة علمية قبل النشر.
- 1080×1920، 24 إطارًا/ثانية، H.264، صوت AAC، ترجمة بكلمات مميزة، انتقالات قصيرة وفحص مسموعية وأبعاد ومدة.
- `edge`: الأصوات الأصلية Ana وAndrew وحدود الكلمات من الخدمة عند توفرها. هذا اتصال بخدمة Edge عبر مكتبة مستقلة، وليس ضمان توفر دائم أو تعهدًا بترخيص تجاري غير محدود.
- `kokoro`: نموذج صوت مفتوح يعمل داخل الجهاز المشغل بعد تنزيله، بدون مفتاح API وبدون رسوم صوت لكل فيديو. **الأصوات مختلفة عن الأصل**. توقيت الكلمات يُشتق من مدد الفونيمات في النموذج، مع استيفاء محلي محدود للكلمات المختزلة. هذا ليس ضمانًا لحدود كلمات مثالية.
- المواضيع الجديدة تحصل على حوار ومخططات سببية متحركة من البيانات. **المخطط العام ليس مطابقًا للمشاهد العلمية المصممة يدويًا لكل ظاهرة**. يمكن إضافة renderer متخصص في `creative/`.

لذلك لا يدّعي المشروع تطابق الجودة تلقائيًا لكل موضوع أو تطابق الأصوات في الوضع المحلي.

## من الموضوع إلى الفيديو

في `new-topic` يعمل Qwen3 4B محليًا بواسطة Ollama داخل runner. يجمع نصوصًا عامة من Wikimedia وأبحاث Europe PMC، أو يقرأ روابط HTTPS التي تدخلها. ثم ينتج JSON للحوار والمخططات والعنوان والوصف والوسوم مع مؤشرات إلى المصادر. لا توجد خدمة نماذج مدفوعة أو مفاتيح مطلوبة.

إذا تعذر الوصول للمصادر أو خرج النموذج ببيانات غير صالحة، يتوقف بدل ادعاء النجاح. النص المولّد **مسودة علمية**، لا يعني وجود رابطين أن جميع الادعاءات صحيحة أو أن هناك إجماعًا. راجع ملفات البحث والادعاءات، خصوصًا النظريات والخلافات العلمية. لا يُنفذ أي نص من المصادر ككود.

افصل المواضيع بعلامة `;` أو بسطر جديد لدفعة مواضيع مختلفة. افصل روابط المصادر بمسافة أو `;`، لأن حقول واجهة Actions أحادية السطر. إذا أدخلت موضوعًا واحدًا ورفعت العدد، ينتج تنويعات حوارية للموضوع نفسه. لا يوجد وعد بأن كل تنويع يصلح للنشر أو أنه فكرة جديدة بالكامل.

## التكلفة والحدود

لا يعتمد المشروع على APIs مدفوعة. المشغلات القياسية في المستودعات العامة مجانية وفق سياسة GitHub الحالية. المستودعات الخاصة تستخدم الرصيد المشمول في الحساب ثم قد تُحاسب إن سمحت ميزانيته. التخزين والمشغلات الأكبر والخدمات الخارجية لها شروط منفصلة. لا تفعّل مشغلًا مدفوعًا أو ميزانية مدفوعة لهذا المشروع.

العدد 1 هو الافتراضي. الحد `max_videos_per_run=20` وحاجز 50 دقيقة إعدادات موارد قابلة للتغيير، وليسا وعدًا بإنجاز 20 فيديو في تشغيل واحد أو ضمن أي رصيد مجاني. لا توجد جدولة تلقائية ولا تشغيل مع كل push.

## الرفع الاختياري إلى القناة

1. جهّز مشروع Google Cloud بلا تفعيل فوترة، وفعل YouTube Data API v3.
2. أنشئ OAuth client من نوع Desktop، واستخدم `curiosity authorize --client CLIENT_FILE --token .secrets/youtube-token.json` على جهاز له متصفح. يمكن تثبيت رمز تفويض مكافئ من مسار OAuth آخر موثوق.
3. احفظ JSON الخاص بالتفويض في **Actions secret** باسم `YOUTUBE_TOKEN_JSON`، ويفضل داخل بيئة `youtube-publish` مع موافقة المالك. لا تضعه في الكود أو الملفات المرفقة أو رسائل المحادثة.
4. شاهد الفيديو الكامل وتحقق من المصادر. افتح **Publish one reviewed video**، وحدد run ID، episode ID، بصمة SHA256 من manifest، والجمهور المطلوب. الافتراضي `private`.
5. اكتب عبارة الموافقة المطلوبة، وفعل تأكيد مراجعة العلم للمسودات الجديدة بعد مراجعتها فعلًا.

إذا كان المستودع عامًا، يمنع مسار Actions رفع فيديو `private` أو `unlisted` لأن سجلات التشغيل وسجل منع التكرار مرئيان. حوّل المستودع إلى خاص قبل استخدام هذين الخيارين. هذا حاجز خصوصية، وليس تفعيلًا تلقائيًا للنشر العام.

الرفع مقفل على قناة `UCEawmiljBdHvnTScqnpPftw`. يتحقق من الحساب قبل الرفع والجمهور بعده. يحتفظ بحجز في `.state/uploads.json` قبل بدء الإرسال. عند نتيجة غير مؤكدة لا يعيد الرفع تلقائيًا، حتى لا يصنع نسخة مكررة. راجع القناة والسجل أولًا. نجاح API لا يعني اكتمال معالجة YouTube أو اجتياز كل فحوصه.

إعداد التفويض لا يثبت نجاح الرفع. اختبارات المشروع تستخدم محاكاة لواجهات YouTube ولا تنشر فيديو عامًا من تلقاء نفسها. تفويضات تطبيقات OAuth الخارجية في وضع Testing قد تحتاج إعادة تفويض دورية، راجع إعداد التطبيق.

## تشغيل محلي

Python 3.11+ وFFmpeg مطلوبان. Linux يعمل مباشرة، والأنظمة الأخرى تحتاج تثبيت FFmpeg المناسب.

```sh
python -m venv .venv
. .venv/bin/activate
pip install -e '.[test,local-voice]'
pytest -q
curiosity generate --episode stomach-growl --voice kokoro --count 1
```

لتوليد موضوع جديد، شغّل Ollama واسحب `qwen3:4b` ثم:

```sh
ollama pull qwen3:4b
curiosity draft --topic 'Why do we get goosebumps?' --out drafts/new.json
curiosity generate --spec drafts/new.json --voice kokoro --count 1
```

الوضع المحلي للصوت يستخدم Kokoro ONNX. يتم التحقق من SHA256 للنموذج والأصوات عند تنزيلهما. تنزيلات النماذج والإنترنت والكهرباء وموارد جهازك ليست موارد لا نهائية.

## الملفات

- `src/curiosity/`: الإدخال، البحث والتوليد، الصوت، التصيير، QA، OAuth والرفع.
- `creative/`: الشخصيات والمشاهد المتخصصة والمخططات العامة والخطوط المرخصة.
- `episodes/`: أمثلة منظمة قابلة للتعديل، مع حالة مراجعة علمية لكل مثال.
- `tests/`: التحقق من البصمة والقناة والازدواج والتسريب الشبكي والمدخلات.
- `docs/`: المصادر وحدود الجودة والأمان.
- `.github/workflows/`: التوليد والرفع اليدوي المنفصلان.

الكود والرسوم الخاصة بالمشروع محفوظة لصاحب المستودع، وليست ممنوحة تلقائيًا بترخيص مفتوح لمجرد ظهورها في مستودع عام. تراخيص المكونات الخارجية تبقى مستقلة، ومنها Quicksand OFL وKokoro Apache-2.0 وkokoro-onnx MIT. راجع `docs/SOURCES.md` و`creative/fonts/OFL.txt`.


## تحديث الجودة: التوليد الجديد والرسوم المتحركة

- يستخدم وضع الموضوع الجديد Manim Community 0.20.1 بمحرك Cairo على المعالج، وليس خدمة رسوم مدفوعة. تتضمن القوالب رسمًا سببيًا متحركًا ومقطعًا مبسطًا للجلد والشعرة والعضلة. اختيار القالب والعبارات بيانات JSON، ولا يُنفذ كود يولده النموذج.
- يحتاج التشغيل المحلي إلى Python 3.11 أو أحدث وFFmpeg وespeak-ng، وإلى مكتبات Cairo وPango عند استخدام `pip install -e '.[motion]'`. يثبت مسار Actions هذه المتطلبات تلقائيًا لوضع الموضوع الجديد.
- يرفض فحص القصة المسودات القصيرة جدًا، والقصص التي تخفي الشخصيات طوال الوقت، والاقتباسات غير الموجودة، وفقدان شروط دراسات الحيوانات أو عبارات عدم اليقين التي يتعرف عليها. يحاول النموذج إعادة الكتابة بحد أقصى ثلاث مرات، ثم يتوقف بدل إخراج فيديو مضلل معروف.
- هذه الفحوص مع قراءة ثانية بالنموذج ليست مراجعة علمية مضمونة. راجع المصادر والنص والفيديو بنفسك قبل اعتماد النشر. تستمر علامة `science_reviewed=false` حتى المراجعة البشرية. فحوص الملف والصوت لا تثبت صحة العلم أو جودة القصة.
- يتم تنزيل النموذج وتشغيله داخل Actions، دون اعتماد على حساب مساعد أو ملفات خاصة. تبقى موافقات حساب Google، وتحديد القناة، وإعداد الأسرار، والمراجعة البشرية خطوات مالك المشروع. لا ينشر مسار التوليد على YouTube.
- الحد الافتراضي فيديو واحد، ولا توجد جدولة دورية مفعلة. الموارد المجانية لها حدود، وقد يفشل تنزيل نموذج أو مصدر أو يتوقف العمل عند مهلة الخمسين دقيقة. لا يفتح المشروع ميزانية مدفوعة تلقائيًا.
